# 时间轴数据

每个文件对应一个 Timeline 分组，文件名就是分组名称，统一导出 `items`。

```ts
import type { Period } from '../types';

export const items: Period[] = [
  ['条目名称', 开始年份, 结束年份],
];
```

年份使用整数，负数代表公元前，不使用 0 年。结束年份不能小于开始年份；相同交替年份不算重叠。单年事件的开始年与结束年相同，界面显示为时间点。

四个地区各有朝代、人物、事件三个文件，共 12 个分组。人物条目表示生卒年，事件表示发生区间。欧洲与美国的“朝代”文件表示历史时期，不意味着存在统一的王朝。这里选取代表性条目，并非完整历史目录。

新增分组时，在 `src/data/groups` 新建文件并导出 `items` 即可，应用自动加载，文件名自动作为分组名称，无需修改组件。现有分组顺序与颜色保持不变；新分组采用官方默认颜色。

贡献时请在数据旁添加史料来源链接及年代争议说明。仍在持续的时期可用 `new Date().getFullYear() + 1` 作为展示边界（不代表已经结束）。
